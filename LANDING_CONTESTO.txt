  2. Il PRECEDENTE featured scende come PRIMO elemento della GRIGLIA
  3. Gli altri card in griglia scalano di una posizione (mantengono ordine)
  4. Aggiornare: stat "Strumenti costruiti", testo intro ("Cinque/Sei/Sette…"),
     CTA ("Tutti i N progetti nel portfolio →")
  5. Aggiungere modal + funzione JS per il demo del nuovo tool

  .project-featured       ← card featured (unica, full-width)
  .badge-nuovo            ← badge "✦ Nuovo" in alto a sinistra del featured
  .featured-body          ← colonna sinistra: icona, nome, desc, meta, CTA
  .featured-kpi           ← colonna destra: 3 KPI numerici
  .project-grid           ← griglia card secondari
  .project-card           ← singola card in griglia
  .modal-overlay          ← wrapper modale (id="modal-XXX")
  .modal                  ← contenuto modale
  .triage-loading         ← spinner durante demo (id="XXX-loading")
  .demo-output            ← area output demo (id="XXX-output")
  .out-row                ← riga chiave/valore nell'output demo
  .out-label              ← etichetta sopra l'output

--------------------------------------------------------------------------------
ARCHITETTURA TECH
--------------------------------------------------------------------------------

- Single file HTML (tutto inline: CSS + JS)
- Zero librerie JS esterne
- Zero backend: chiamate API demo sono simulate (setTimeout 2000ms)
- Modali: funzione openModal(id) / closeModal(id)
- Demo simulate: ogni tool ha runXXX() con dati pre-scritti
- Dark mode: non implementata in landing (solo in index.html e nei tool)
- Analytics: Umami (script asincrono in <head>)
